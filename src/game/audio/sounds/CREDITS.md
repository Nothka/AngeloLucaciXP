# Sound credits

Every recording in this folder is released under **Creative Commons 0 (CC0 1.0, public domain
dedication)**: <https://creativecommons.org/publicdomain/zero/1.0/>. CC0 allows any use, including
commercial, with no attribution required. We credit the creators anyway, with thanks.

- **Freesound** (<https://freesound.org>): the licence of each file was checked on its own page
  (October 2026). Files are Freesound's 128 kbps MP3 previews.
- **Kenney** (<https://kenney.nl>): Impact Sounds, RPG Audio and Interface Sounds packs; each pack's
  `License.txt` states CC0. Converted from OGG to mono 22 kHz WAV so every browser can play them.

The game trims silence, evens out loudness and fades the edges when it loads a file. Files named
`*_calls-*` hold several calls in one recording; the game splits them into separate sounds.

Excluded on purpose: remixes of other people's recordings, human imitations of animals, uploads of
unclear origin, and uploads whose author asks for credit despite a CC0 tag.
